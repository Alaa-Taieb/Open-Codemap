# Security Policy

## Supported Versions

The latest published `open-codemap` release receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

- Use GitHub's private **Security → Report a vulnerability** advisory, or
- Email the maintainers at security@open-codemap.dev (replace with real address).

We aim to acknowledge reports within 72 hours and provide a remediation timeline within 7 days.
